# Lucky Draw Static Website

This repository contains a simple static website for a lucky draw application. It includes:

- `index.html` – the main page
- `style.css` – styling for the site
- `js/` – JavaScript modules handling animation, navigation, rendering, settings, and state management

The site is built with plain HTML, CSS, and vanilla JavaScript, making it easy to host on any static file server or GitHub Pages.

## How to Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/mims1234/lucky-draw-static.git
   ```
2. Open `index.html` in a web browser.
